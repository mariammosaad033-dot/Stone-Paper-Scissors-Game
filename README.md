Rock Paper Scissors Game 🎮

This is a simple Rock Paper Scissors game made using C++.

About the Game

The player chooses one of:

- Paper
- Stone
- Scissors

The computer chooses randomly, and the game decides who wins each round.

You can choose the number of rounds from 1 to 10.

At the end of the game, it shows:

- Player wins
- Computer wins
- Draws
- The final winner

What I Used

- C++
- Functions
- Structs
- Enums
- Loops
- Switch
- Random Numbers

How to Play

Run the program and enter the number of rounds.

Then choose:

[1] Paper
[2] Stone
[3] Scissors

After all rounds, you will see the final result.
